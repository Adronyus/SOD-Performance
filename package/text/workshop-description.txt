SOD Performance makes Shadows of Doubt run smoother, above all in big cities: higher FPS, far fewer stutters and faster city loading.
The game itself stays exactly the same: same city, same citizens, same rules. Only the way the work is done changes.

[h1]Requires SOD Extender (one-time install)[/h1]
SOD Performance is a [b]code mod[/b]. Steam can't run code mods on its own, so you need SOD Extender once. After that, code mods work like any other Workshop subscription.

[olist]
[*]Download SOD Extender: open [url=https://github.com/XRenso/sod-extender/releases]SOD Extender on GitHub[/url] and, under [b]Assets[/b] of the newest release, click [b]SodExtender-0.3.0.zip[/b] (or a newer version).
[*]Steam -> Shadows of Doubt -> right click -> Manage -> [b]Browse local files[/b]. Unzip the whole download into that folder (next to "Shadows of Doubt.exe").
[*]Subscribe to SOD Performance (this page).
[*]Start the game. The [b]first start takes 1-2 minutes longer[/b] (normal; again after game updates).
[*]Main menu -> [b]Mods[/b]: make sure SOD Performance is enabled. The [b]SOD Extender[/b] button shows that it loaded.
[/olist]
Already using the Thunderstore / BepInEx version of SOD Performance? Remove it ([i]BepInEx/plugins/SODPerformance[/i]). Only one copy can run.

[h1]Why the game stutters[/h1]
To run at 60 FPS, the game has 16.7 ms for each frame. Most of the game's logic (citizens, AI, rooms, objects) runs on [b]one CPU thread[/b]. When a single frame needs 100+ ms there, you see a hitch, however fast your graphics card is. That's why graphics settings, DLSS or V-Sync barely help: the problem is on the CPU, and it grows with the city.

[h1]What it fixes[/h1]
[list]
[*][b]Citizens moving in lockstep:[/b] the game moves [i]all[/i] far-away citizens in the same frame: about 1,900 citizens every 3.4 seconds in a big city, a ~110 ms freeze each time. The mod spreads them evenly over time. Each still moves as often.
[*][b]AI decisions piling up:[/b] the game limits citizen decisions per frame by count, not by time, so a few slow ones (fights, crowds) stack into a freeze. The mod gives them a time budget of 4 ms per frame; the rest continue in the next frame.
[*][b]Stutters at every door:[/b] entering a building shows dozens of rooms and loads each room's furniture (20-30 ms per room) in the same frame. The mod shows nearby rooms at once and loads the rest nearest-first over the next frames, never later than a quarter of a second.
[*][b]Freezes in new rooms:[/b] the game recalculates which rooms can see each other for the whole city on every load. Walking into a room that isn't done yet freezes for 100-300 ms. The mod saves this per city, so later loads skip that work.
[*][b]Slow loading:[/b] while building a city's evidence, the game compares objects millions of times through a slow, locked type lookup, about 55 s of a 138 s load in testing. The mod uses a comparison with exactly the same result without the lock. The evidence step dropped from 54 s to about 13 s.
[*][b]Breaker box search:[/b] every new camera, alarm or light searched every object in the city for its breaker box. The mod uses a direct index.
[*][b]Shadows nobody sees:[/b] about 250 lights drew shadows every frame at any distance. Lamp shadows now fade out a bit earlier.
[*][b]Smaller fixes:[/b] sound occlusion is updated one frame after a room change, and the costly stack traces behind the game's many log warnings are skipped.
[*][b]AMD X3D CPUs[/b] (7950X3D, 9950X3D, ...): keeps the game on the cores with the extra 3D V-Cache.
[/list]

[h1]Settings[/h1]
File: [i]BepInEx/config/SodMods/SOD Performance.cfg[/i] (created on first start; edit it with the game closed). Every fix has its own switch. The most useful ones:
[list]
[*][b][AI] FrameBudgetMs = 4[/b]: time for citizen decisions per frame (0 = vanilla)
[*][b][AI] StaggerFarMovement = true[/b]: spread far-away citizen movement
[*][b][Rooms] SmoothRoomContentLoading = true[/b]: furniture nearest-first in small steps
[*][b][Loading] RoomVisibilityCache = true[/b]: save room visibility per city
[*][b][Shadows] DistanceScale = 0.5[/b]: 1 = vanilla shadow distance
[*][b][CPU] PreferVCacheCores = true[/b]: X3D CPUs only
[/list]

[h1]Good to know[/h1]
[list]
[*]Start a new save to get the full performance boost. On existing saves, the improvement may be barely noticeable.
[*]The first load of a city builds its room visibility cache ([i]BepInEx/cache/SODPerformance[/i]). Later loads of the same city are faster.
[*]For the best memory use, restart the game before loading a different city.
[*]Some lamps can look slightly brighter, because their shadows fade out earlier. Set [b][Shadows] DistanceScale = 1[/b] for the vanilla look.
[*]After a game update, each fix checks the game at start-up and switches itself off if something it relies on has changed, instead of breaking the game.
[*]Doesn't touch your saves. Unsubscribe or disable it in the Mods menu at any time.
[/list]

[h1]Compatibility[/h1]
Tested alongside CityRenewal. If another mod changes the same systems (AI, room loading), the SOD Extender button in the Mods menu lists the overlaps. If something seems off, try one mod at a time.

[h1]FAQ[/h1]
[b]What does F7 do?[/b] It saves a text report about how the game runs on your PC to [i]BepInEx/SODPerformance[/i]: your CPU and GPU model, FPS and worst frames with the mod on and off, every stutter and what the game was busy with, how long each loading step took, memory use, and what each fix did. Open it with Notepad. It's only for you: nothing is uploaded or sent anywhere.
[b]The mod doesn't load.[/b] Check that SOD Extender is installed (step 2) and that the SOD Extender button appears in the Mods menu. Its report shows why a mod didn't load.
[b]Still some stutters?[/b] A few remain from Unity's memory cleanup, plus a one-time freeze right after a city finishes loading (both are in the vanilla game too). Work on these continues.

[h1]See it for yourself[/h1]
You don't have to take my word for it. Load a big city, walk around and press [b]F10[/b] to switch between vanilla and the mod, with [b]F8[/b] open to watch the numbers. Press [b]F7[/b] for a full report (see the FAQ). For a breakdown of where each frame's time goes, set [b][Profiler] Enabled = true[/b] (small overhead).
The mod collects nothing and sends nothing; reports stay on your PC.
